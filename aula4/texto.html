Elementos de Manipulação de Texto em HTML

O Guia que Todo Iniciante Precisa Ler

HTML?

O HTML é a linguagem padrão usada para criar e estruturar páginas na internet.
Ele serve para o conteúdo de um site, indicando ao navegador como cada elemento deve ser apresentado.

CSS

CSS é uma linguagem de estilo usada para definir a aparência visual de páginas na internet.
Permitindo que você controle cores, fontes, espaçamento, layout, tornando a experiência dos usuários mais agradável e consistente.

Cabeçalhos

Os elementos de cabeçalho são responsáveis pela organização hierárquica do conteúdo da página.
São representados pelas tags h1(mais importante) à h6(Menos importante).

Parágrafos

O elemento de parágrafo representado pela tag p é usado para agrupar blocos de texto relacionados,
inserindo uma quebra de linha automática antes e depois do conteúdo, garantindo uma melhor legibilidade.

Quebra de linha

O elemento de quebra de linha representado pela tag br é usado para inserir uma quebra de linha dentro de um parágrafo ou outro elemento de bloco.
